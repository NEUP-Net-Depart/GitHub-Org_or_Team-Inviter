# ============================================================
# 名单示例文件
# ------------------------------------------------------------
# 用法: 复制本文件改成你自己的名字(例如 名单.txt), 把下面的
#       alice / bob / carol 换成真实的 GitHub 用户名, 然后:
#
#   python github_inviter.py --org my-org 名单.txt --execute
#
# 规则:
#   * 每行一个用户名或邮箱; 空行和以 # 开头的行会被忽略
#   * 每行只取第一个逗号/分号/制表符/多空格分隔的字段
#     —— 所以从表格里直接复制 "用户名,邮箱,备注" 也能用
#   * @前缀 和 https://github.com/xxx 链接都认
#   * 重复项会自动去重, 大小写不敏感
# ============================================================

alice
bob
@carol
dave@example.com
