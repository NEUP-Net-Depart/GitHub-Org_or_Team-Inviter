# 规则:
#   * 每行一个 GitHub 用户名(也可以写邮箱)
#   * 空行、以及 # 开头的行会被忽略
#   * 每行只取第一个逗号/分号/制表符分隔的字段
#     —— 所以从表格里整行粘过来的 "用户名,邮箱,备注" 也能用
#   * @前缀 和 https://github.com/xxx 链接都认
